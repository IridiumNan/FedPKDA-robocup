# UI 界面参考

## 设计原则

> 来自 `Aufait UX`

- 安全仪表盘的核心是 **at a glace** -> 3s 内判断有没有事情
- 优先级视觉展示: 🟢 代表状态正常，不闪烁; 🟡 代表可疑异常，建议操作; 🔴 告警自动阻断;
- 数字带有参考值 (排名，趋势等),不能直接摆，否则信息参考价值低
