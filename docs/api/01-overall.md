# 平台概览 API

> 对应页面：`MVP_frontend/light/index.html`（平台概览）
> 接口前缀：`/overall`
> 权限：协调员 / 运营员均可访问

---

## 1. GET /overall/best_acc

**用途**：获取平台最佳检测率及与基线（FedAvg）的对比，对应首页"最佳检测率"与"FedAvg 提升"两张指标卡。

**查询参数**：无

**响应字段**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| time | str | 服务端时间戳 |
| acc | float | 当前最佳检测率（百分比数值），如 `45.1` 表示 45.1% |
| compare | float | 相比 FedAvg 基线的提升量（百分点），如 `17.3` 表示 +17.3pp |

**示例**

```json
{
    "time": "2026-08-03 15:30:00",
    "acc": 45.1,
    "compare": 17.3
}
```

---

## 2. GET /overall/node_num

**用途**：获取联盟参与机构数量，对应首页"参与机构"指标卡（含新增数）。

**查询参数**：无

**响应字段**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| time | str | 服务端时间戳 |
| num | int | 当前参与机构总数 |
| new_num | int | 本周期新增机构数 |

**示例**

```json
{
    "time": "2026-08-03 15:30:00",
    "num": 24,
    "new_num": 3
}
```

---

## 3. GET /overall/round

**用途**：获取当前训练轮次进度，对应首页"训练轮次"指标卡（如 38/40）。

**查询参数**：无

**响应字段**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| time | str | 服务端时间戳 |
| round | int | 当前已完成的训练轮次 |

**示例**

```json
{
    "time": "2026-08-03 15:30:00",
    "round": 38
}
```
