## 四、技术选型

### 当前技术栈

| 工具 | 用途 |
| --- | --- |
| Python 3.12 + PyTorch | 核心算法 |
| Scikit-learn | 马氏距离、K-Means |
| HTML + CSS + Vanilla JS | 前端 Demo（MVP_frontend/light/） |
| UNSW-NB15 | 网络安全数据集 |
| Cifar100 | 基准数据集 |

### UI Demo 设计思路

当前 Demo 使用纯 HTML/CSS/JS 构建，没有框架依赖：

- **选择原因**：不需要前端工程师，直接浏览器打开即可查看
- **数据策略**：全局态势的检测率曲线使用已跑完的四组 Cifar100 实验数据（`experiment_data.json`）
- **策略数据**：节点状态、行为评分、安全事件使用模拟数据，但 schema 与真实算法输出一致
