# 系统架构与数据流

---

## 一、核心工作流程

每轮训练是一个固定的八步循环：

```
① 本地训练
   各机构在自己的网络流量数据上训练本地特征提取器

② 原型提取
   从特征提取器输出中计算每个攻击类别的特征中心

③ 加噪上传
   裁剪到 [-1,1] + 拉普拉斯噪声 → 上传到中心服务器
   （原始数据从未离开机构服务器）

④ 服务端聚合
   K-Means 聚类 → 马氏距离计算 → 距离加权平均
   → 生成全局原型         ↗ 异常节点自动降权

⑤ 全局原型广播
   全局原型发回各机构

⑥ 双对齐训练
   各机构用全局原型做本地对齐 (L_LA) + 全局对齐 (L_GA)
   φ(t) 自动调节两者权重（早期偏本地个性化，后期偏全局泛化）

⑦ Fisher 加权聚合模型
   各节点的模型贡献度天然量化，搭便车自动降权

⑧ 进入下一轮
```

### 详细的数据链路

**Client → Server（上行链路）：**

```
本地数据
  → 特征提取器 → 特征向量
  → 裁剪 + 计算本地原型（类别的中心）
  → 添加拉普拉斯噪声
  → 带噪声的原型上传至服务器
```

**Server → Client（下行链路）：**

```
收集所有在线客户端的带噪声的原型
  → K-Means 聚类，找到中心
  → 计算马氏距离（考虑协方差分布）
  → 加权生成全局原型
  → 广播全局原型给客户端

同时：
  → Fisher 信息矩阵计算客户端贡献度
  → 加权聚合全局模型参数
  → 下发给所有客户端
```

## 三、事件触发点

| 在哪一步 | 触发事件 | 进入事件中心 |
| --- | --- | --- |
| 步骤④ | 某节点马氏距离 > 3σ | "节点 X 行为偏离" |
| 步骤④ | 某节点 N 轮未响应 | "节点 X 已离线" |
| 步骤④ | 每轮聚合完成 | "第 N 轮训练完成" |
| 步骤⑧ | 连续 N 轮检测率下降 | "检测率持续下降" |
| 步骤② | 本地模型检出未知攻击 | "新攻击模式（匿名）" |

## 五、为什么这个系统有价值？

每个机构都需要入侵检测，但单家机构能看到的攻击样本太少。
联盟的价值：**别人被打过的东西，你的模型能学会防御；但别人不会知道你被打过。**

| 利益 | 实现机制 | 为什么可以信任 |
| --- | --- | --- |
| 模型效果提升 | 全局原型聚合 + 双对齐 | 见过自己没见过的攻击模式 |
| 个性化保留 | φ(t) 动态调节，早期偏本地 | 银行模型不会因电力数据退化 |
| 搭便车不被容忍 | Fisher 加权聚合 | 贡献低的节点自动降权 |
| 知识自动传播 | 攻击检测 → 原型更新 → 全局聚合 | 不需要任何人主动报告 |

## 六、风险怎么消除？

利益实现和风险消除是同一套机制——不是两件事。

| 风险 | 消除机制 | 是算法还是架构？ |
| --- | --- | --- |
| 原始数据泄露 | 传输原型而非梯度（PSNR 6.9，数学不可逆） | 算法 |
| 恶意节点污染全局模型 | 马氏距离自动隔离异常原型 | 算法 |
| 机构被攻陷不自知 | 马氏距离自动标记，事件中心告警 | 算法 |
| 协调员成为数据集中风险点 | 协调员技术上拿不到原型和数据 | 架构 |
| 被攻击的声誉风险 | 安全事件仅自己可见，协调员只能看匿名通知 | 架构 |
| 隐私合规风险 | 内置拉普拉斯噪声，ε 可配置可审计 | 算法 |
| 节点掉线无人知道 | 心跳超时 → 事件中心告警 | 架构 |

## 七、前端-算法映射

### 算法输出 → 前端展示

| FedPKDA 内部计算 | 产出 | 前端展示 |
| --- | --- | --- |
| `compute_global_prototypes()` 马氏距离 | 每个客户端的异常分数 | 节点行为评分（0-100） |
| `rs_test_acc` | 每轮全局测试精度 | 全局检测率 + 趋势折线图 |
| `Func` φ(t) | 当前个性化/全局化程度 | 训练阶段指示器 |
| Fisher 信息聚合 | 每个客户端的贡献权重 | 节点贡献度 |
| `get_noisy_local_prototypes()` 噪声参数 | Laplace 噪声尺度 | 隐私保护强度指示器 |
| 全局模型本地推理 | 攻击检测结果 | 安全事件时间线 |

### 用户操作 → 算法参数

| 用户操作 | 对应的算法变更 |
| --- | --- |
| 协调员调整 global_par | 修改 `set_parameters()` 中的全局对齐权重 |
| 运营员隔离自己的节点 | 该节点不上传原型到 `compute_global_prototypes()` |
| 运营员调整噪声强度 | 修改 `get_noisy_local_prototypes()` 的 Laplace scale |
| 运营员切换训练/评估/空闲 | 改变该客户端在 `send_selected_models()` 中的身份 |
| 协调员建议隔离 | 不改变算法，仅生成通知记录 |
